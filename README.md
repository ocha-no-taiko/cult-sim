# CULT ~Congregation Under Local Tycoon~

**▶ [ブラウザで遊ぶ](https://ocha-no-taiko.github.io/cult-sim/)**

新興宗教の教祖となり、教義を設計し、布教で信者を集め、事業と宗教都市を広げ、
最終的に政党を第一与党へ押し上げる（＝国教化する）ブラウザ経営シミュレーション。
教団名・出版局名・学校名・財団名・政党名はプレイヤーが自由に決められる。

インストール不要・サーバー不要。すべてブラウザ内で完結し、進行は自動でブラウザに保存される。

> これは架空の教団を経営するシミュレーションゲームです。実在の宗教団体・政党・人物とは一切関係ありません。

## 手元で動かす

```bash
npm install
npm run dev
```

ブラウザで表示されたURLを開く。ビルドは `npm run build`（`dist/` は静的ホスティングにそのまま置ける）。
`main` に push すると GitHub Actions が自動でビルドし、GitHub Pages へ配信する。

## 全体の流れ

拠点選択 → 教義設計 → 開教 → 事業拡大（出版 → 教育 → 財団） → 宗教都市化・支部拡大
→ 政党設立 → 総選挙で第一与党を獲得してクリア

## 四つの決着と三つの敗北

| 決着 | 条件 | 目安 |
|---|---|---|
| **第一与党** | 政党を設立し、総選挙で第一党の得票率を上回る | 約400日 |
| **国家転覆** | 暴力団と盟約を結び、闇度95以上で信者500万人 | 約330日・成功率5割 |
| **国民の半分** | 全人口の50%を信者にする（国教化後に上限が上がる） | 約600日 |
| **コングロマリット** | 表と裏の全11事業を設立し、運転資金30兆円 | 約1,500日 |

| 敗北 | 条件 |
|---|---|
| **資金枯渇** | 運転資金が3日連続でマイナス |
| **強制捜査** | 世間の警戒度が100に達する |
| **教祖暗殺** | 闇度80超で、日ごとの抽選に当たる |

どの決着に到達しても「統べ続ける」を選べば経営を続けられ、別の決着も狙える。敗北条件は最後まで残る。

## 宗教都市と配置シナジー

5×5の区画に施設を建てる。表示は**立体（等角投影）と平面（真上から）をパネル右上のボタンで切り替えられる**。
選んだ表示はブラウザに記憶され、次に開いたときも同じモードで始まる。
どちらの表示でも建物は**ドラッグで移動**でき、区画が埋まっていれば入れ替わる。教会本部も動かせる。

- **立体**：建物の高さと屋根の形で種類が分かる。都市が育っていく手応えを見るならこちら
- **平面**：区画の位置関係と稼働状況が一目で読める。シナジーを組み替えるときはこちら

配置そのものが性能になる。

- **隣接シナジー**：出版局＋放送局、集会所＋修練道場、神学校＋出版局など、直交で隣り合うと効果が加わる（9種）
- **本部の威光**：教会本部に接する8区画の施設は、その効果が15%増し
- **中心に坐す本部**：教会本部を都市の中央に据えると、全施設の効果が4%増し
- **外周ボーナス**：外周の布教所は布教が伸び、外周の出版局・放送局は収益が増え、外周の財団事務局は警戒度をさらに下げる

成立しているシナジーは金色の破線で地図上に図示され、「配置シナジー」パネルで一覧できる。
定義は `src/content/synergies.json` にあり、自由に追加・変更できる。

## 表の事業と裏の事業

表は **出版 → 教育 → 医療福祉 → 財団 → 芸術文化 → 政党** の6つ。
医療福祉（慈恵病院）・芸術文化（文化会館）・財団（財団事務局）は、いずれも世間の警戒度を下げる。
奉仕活動やイメージ刷新キャンペーンといった布教施策でも下げられる。

裏は **情報工作 → 歓楽事業 → 金融事業 → 薬物流通 → 暴力団との盟約** の5つ。
収入は表とは桁が違うが、**闇度**というもうひとつのゲージを押し上げる。

- 闇度70超：暗殺未遂が起きうる（教祖が20日動けなくなる）
- 闇度80超：暗殺によるゲームオーバーが現実になる
- 闇度95以上＋信者500万人：**国家転覆**の決着に届く

裏の施設は配置を解除すれば闇度が自然に下がる。踏み込む深さと引き返す時機を、自分で決めることになる。
裏に一度も触れずに国教化まで行くこともできる。

## 押さえどころ

- **教祖はひとりしかいない**。施設を稼働させるには「教祖を常駐させる」か「規定数の聖職者を配置する」かの二択で、
  教祖を施設に入れている間は教義改定・事業設立・教祖を要する布教ができない。
- **最初の聖職者は教祖が育てるしかない**。神学校に教祖を入れて聖職者を作り、教祖を解放していくのが序盤の山場。
- **聖職者を増やすと信者が減る**。転向した分のお布施は失われる。手を増やすか実入りを取るかは毎日の判断。
- **急拡大は警戒度を押し上げる**。警戒度は高いほど自然に鎮まるので均衡点があり、財団と政界工作でその均衡を下げられる。
- **得票率は展開した全地方の信者率の合算**。拠点地方だけでは第一与党には届かない。

## 対戦モード

同じ時計の上で複数の教団が同時に国を狙う。**決着に最初に辿り着いた教団が勝つ。**
遊ぶには対戦サーバが要る（[server/README.md](server/README.md)）。

```bash
npm run build
cd server && npm install && npm start
```

参加者は `http://<サーバのTailscale名>:8787/` を開き、同じ部屋IDと合言葉を入れる。

- **時間は止められない**。1日の長さは、参加者それぞれが出した希望の平均で決まる
- 見えるのは他教団の**信者数・資金・警戒度・全人口比・表の事業**まで。**闇度だけは誰にも見えない**
- 表の事業を設立すると全員に通知が飛ぶ。財団・病院・文化会館は闇度もわずかに薄めるので、
  「表を厚くしている教団は、清廉なのか、闇を隠しているのか」を読むことになる
- **暗殺**：1日に一度だけ、他教団の教祖を狙える（4億円）。闇の濃い側が勝つ
  - 実行には自分の闇度が30以上必要（裏社会のつてが要る）
  - 相手も闇度30以上でないと手がかりが掴めない
  - 自分の方が濃ければ成功、薄ければ失敗して自分の闇度が跳ね上がる
  - 相手が25以上も上回っていれば**逆襲**され、こちらが終わる
- 脱落した教団も、他教団の統計を最後まで眺められる

## 構成

```
src/
  content/     ゲーム内容のJSON（文言・数値・シナジー・決着条件・手引き・進行）
  game/
    data/      content/ のJSONを読み込んで配列・辞書に整えるだけの薄い層
    engine/    状態、派生値（selectors）、配置とシナジー（city）、1日進行（tick）、アクション（actions）
    format.js  円・人数の表示整形
  components/  画面とUI部品（CityMap が等角表示とドラッグ移動を担当）
tools/
  balance-sim.mjs  ヘッドレスのバランス検証AI
server/
  index.mjs        対戦サーバ（WebSocket＋ゲーム本体の配信）
  rules.mjs        暗殺・時計などクライアントに任せられない判定
  test-match.mjs   対戦ルールの検証
src/net/
  match.js         対戦サーバとの接続
```

### バランス検証

単純な方針のAIに最後までプレイさせて、到達日数と敗因を確認できる。

```bash
node tools/balance-sim.mjs normal kanto          # 施策を全部盛りする無謀なAI
CAUTIOUS=1 node tools/balance-sim.mjs normal kanto  # 警戒度を見て絞る慎重なAI
TRACE=1 CAUTIOUS=1 node tools/balance-sim.mjs normal kyushu  # 20日ごとの推移を出力
```

`ROUTE` で建て方と狙う決着を変えられる。

```bash
CAUTIOUS=1 ROUTE=light node tools/balance-sim.mjs normal kanto   # 王道（第一与党）
ROUTE=greedy  node tools/balance-sim.mjs normal kanto             # 警戒度対策を怠る
ROUTE=uprising node tools/balance-sim.mjs normal kanto            # 裏ルート（国家転覆）
KEEP_GOING=1 MAX_DAYS=5000 CAUTIOUS=1 ROUTE=mass node tools/balance-sim.mjs easy kanto     # 信者50%
KEEP_GOING=1 MAX_DAYS=6000 ROUTE=economy node tools/balance-sim.mjs easy kanto             # 30兆円
```

現状の目安（標準・関東）：王道は約400日で第一与党。警戒度対策を怠ると約250日で強制捜査。
裏ルートは約330日で国家転覆だが、半分は暗殺か強制捜査で終わる。
検証AIは配置シナジーを考慮せずに建てるため、シナジーを意識すればこれより早く勝てる。
